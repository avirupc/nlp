# Summary

[📖 Chapter link](https://huggingface.co/learn/llm-course/chapter5/7)

From Chapter 5, we learnt how to
- Load datasets from anywhere, be it the Hugging Face Hub, your laptop, or a remote server.
- Wrangle data using a mix of the `Dataset.map()` and `Dataset.filter()` functions.
- Quickly switch between data formats like Pandas and NumPy using `Dataset.set_format()`.
- Create our very own dataset and push it to the Hugging Face Hub.
- Embed documents using a Transformer model and build a semantic search engine using FAISS.
